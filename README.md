# 🌸 Iris Classification using Scikit-learn

A simple Machine Learning project that classifies Iris flowers into different species using the Scikit-learn library.

## 📌 Project Overview

This project demonstrates the complete machine learning workflow:

- Loading the Iris dataset
- Data preprocessing
- Training a classification model
- Testing the model
- Evaluating model accuracy

It is designed as a beginner-friendly introduction to machine learning with Python.

---

## 🛠️ Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- Jupyter Notebook

## 📊 Dataset

The project uses the famous **Iris Dataset**, which contains measurements of Iris flowers and predicts one of the following species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/dhruvTerminal/iris-classification-sklearn.git
```

2. Install dependencies

```bash
pip install pandas numpy scikit-learn jupyter
```

3. Open Jupyter Notebook

```bash
jupyter notebook
```

4. Run the notebooks.

The notebook trains a machine learning classifier and reports its prediction accuracy on the Iris dataset.
